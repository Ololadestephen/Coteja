COTEJA DEMO CHEATSHEET — TRANSPARENT RECORDING
===========================================================

BEFORE RECORDING
  1. Close unrelated apps and notifications.
  2. Set Terminal font to 17pt or larger.
  3. cd ~/Documents/aleph/coteja
  4. Pre-warm the already-downloaded models.
  5. Turn Wi-Fi OFF and keep the menu-bar state visible.
  6. Start a full screen recording for the product run.

VERIFY FIRST
  npm run typecheck
  npm run coteja -- --selftest

FULL END-TO-END RUN
  npm run coteja -- dossiers/messy --out reports

  Keep the entire capture. In the final edit, speed up only the waiting section
  and overlay: "13m35s measured local run — middle shown at 20×".
  Return to normal speed before the packet prints.

PACKET SHOTS
  1. reports/messy-photo.packet.md
     Show verdict, calculation and both source citations.
  2. reports/adversarial-injection.packet.md
     Show pre-extraction redaction flags and shipment-date discrepancy.
  3. reports/reliability.md and reports/bench.json
     Say "12/12 expected verdicts; rule-ID metrics; verdict consistency".
  4. dossiers/field-capture/
     Say "one recorded phone-camera run on synthetic documents".

CLOSE
  git status --short --branch
  git log --oneline -8
  Show https://github.com/Ololadestephen/Coteja

IF A CAPTURE FAILS
  Stop and re-record the failed segment. A previously generated packet may be
  shown only when it is clearly labelled as a prior recorded run. Never imply
  that a cached artifact was generated by the command currently on screen.
===========================================================
